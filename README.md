# IPL Win Predictor

A simple Streamlit app that predicts the probability of the batting team winning an IPL match based on the current game situation.

## Features

- Real-time probability estimates for match outcomes
- Interactive Streamlit interface
- Custom inputs for batting team, bowling team, city, score, overs, wickets, and target

## Run locally

1. Create and activate a Python environment.
2. Install the dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Launch the app:
   ```bash
   streamlit run app.py
   ```

## Run tests

```bash
pytest
```
